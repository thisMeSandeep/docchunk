Copy one of these prompts into your AI coding agent, such as Claude Code, Cursor, or Codex. The agent reads the Doc-chunk documentation, installs the library, writes the code, runs it on a real document, and shows you the result.

Choose the prompt that matches your project:

- **Add to an existing pipeline** when your project already embeds documents, and you want Doc-chunk to do the splitting.
- **Start from scratch** when you want a script that turns a folder of documents into chunks.

## Tips

- **Fill in your goal.** In the second prompt, replace the text in angle brackets. For example: "PDF contracts, searched by a support chatbot that uses a 512-token embedding model". The agent uses it to choose the strategy and size.
- **Install the skill as well.** With the [agent skill](../agent-skill/) installed, the agent keeps using Doc-chunk correctly in later tasks, not only during setup.
- **Check the plan.** The first prompt asks the agent to describe its plan before it changes code. Read it, especially what it will replace.

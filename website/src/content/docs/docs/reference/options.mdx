Options are the second argument of [`chunkDocument`](../chunk-document/) and [`chunkDocuments`](../chunk-documents/). Every option is optional. An option that the chosen strategy doesn't accept throws an `INVALID_OPTIONS` error, and so does a value that breaks the rules below.

All sizes are in characters.

## Common options

These work with every strategy.

| Option | Type | Default | Description |
|---|---|---|---|
| `strategy` | `string` | `"structure"` | The [strategy](../../strategies/) to use. One of `"structure"`, `"heading"`, `"paragraph"`, `"sentence"`, `"sentence-window"`, `"parent-child"`, `"hierarchical"`, `"recursive"`, `"fixed"`, `"fixed-overlap"`, `"sliding-window"`. |
| `metadata` | `object` | `{}` | Copied onto every chunk's `metadata`. Doesn't change chunk ids. Must be an object, not an array. |
| `documentId` | `string` | Hash of the document | Used as `document.id` and in every chunk id. A non-empty string. |
| `headingPrefix` | `boolean` | `false` | Adds the heading path (`A > B > C` and a blank line) to the start of each chunk's text. Counts toward the size limit. |
| `signal` | `AbortSignal` | None | Stops chunking with an `ABORTED` error when aborted. |

| | `boundary` | `"word"` or `"char"` | `"word"` | One of the two values. |

Each strategy page explains what its options do.

### Options that depend on each other

- **`minSize` and `size`.** `minSize` can't be larger than `size`. For `structure`, when you set a `size` below 200 and no `minSize`, the default `minSize` becomes equal to `size`.
- **`overlapChars` and `size`.** `overlapChars` must be less than `size`.
- **`childSize` and `parentSize`.** `childSize` must be less than `parentSize`.
- **`step` and `size`.** `step` can't be larger than `size`.
- **`headingPrefix` and the sizes.** With `headingPrefix`, each size option is reduced by the length of the longest heading path in the document, so that prefixed chunks still fit. If that leaves no room, chunking fails with `INVALID_OPTIONS` after the document is read.

## Batch options

[`chunkDocuments`](../chunk-documents/) accepts every option above, plus:

| Option | Type | Default | Description |
|---|---|---|---|
| `concurrency` | `number` | `4` | Documents chunked at the same time. A positive integer. |

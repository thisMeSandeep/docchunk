This page runs every strategy on the same short document, so you can see where each one puts its chunk boundaries. The size-based strategies use sizes of 100 to 400 characters, because the document is small.

## The document

```md title="returns-policy.md"
# Returns policy

You can return most items within 30 days of delivery. Items must be unused and in their original packaging.

## Start a return

1. Sign in and open **Orders**.
2. Choose the item you want to return.
3. Print the prepaid shipping label.

## Refunds

We refund the original payment method within 5 business days of receiving the item. Shipping costs are not refunded.

| Item | Refund |
| --- | --- |
| Unused item | Full price |
| Opened item | 80% |
```

## What to look at

- **`structure`, `heading`, `paragraph`, and `recursive`** give almost the same chunks here, because each section is small. They differ on longer documents: `heading` never splits a section without `size`, `paragraph` never packs blocks together without `size`, and `recursive` can join small sections.
- **`sentence` and `sentence-window`** have the same `text`. The difference is `contextText`, which this page doesn't show. Neither includes the headings in the text.
- **`parent-child` and `hierarchical`** cover the same text once per level, so their chunks add up to more text than the document has. Usually only one level is embedded.
- **`fixed`, `fixed-overlap`, and `sliding-window`** cut through the list and the table. `fixed-overlap` and `sliding-window` also start chunks in the middle of words.

## The script

The output above comes from this script:

```ts
import { type ChunkOptions, chunkDocument } from "docchunk";

const runs: ChunkOptions[] = [
  { strategy: "structure", size: 200, minSize: 50 },
  { strategy: "heading" },
  { strategy: "paragraph" },
  { strategy: "sentence" },
  { strategy: "sentence-window" },
  { strategy: "parent-child", parentSize: 300, childSize: 100 },
  { strategy: "hierarchical", levels: [400, 150, 100] },
  { strategy: "recursive", size: 200 },
  { strategy: "fixed", size: 200 },
  { strategy: "fixed-overlap", size: 200, overlapChars: 50 },
  { strategy: "sliding-window", size: 200, step: 100 },
];

for (const options of runs) {
  const { chunks, stats } = await chunkDocument(
    { path: "returns-policy.md" },
    options,
  );
  const sizes = `${stats.minChars} to ${stats.maxChars} chars`;
  console.log(`## ${options.strategy}: ${stats.count} chunks, ${sizes}`);
  for (const chunk of chunks) {
    const indent = "  ".repeat(chunk.level ?? 0);
    const lines = chunk.text.split("\n");
    const preview = lines.length === 1 ? lines[0] : `${lines[0]} … ${lines.at(-1)}`;
    console.log(`${indent}${chunk.charCount} | ${preview}`);
  }
}
```
